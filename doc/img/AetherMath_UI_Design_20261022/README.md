# AetherMath UI 화면 모음

AetherMath 수학 편집기 UI 화면 5종과 화면별 주요 기능을 한국어 번호/콜아웃으로 표시한 주석 이미지입니다.

## 구성

- `원본/` — 사용자가 제공한 원본 이미지 5개를 보존한 폴더입니다.
- `주석/` — 각 화면의 주요 영역과 기능을 번호로 연결한 주석 이미지 5개입니다.

## 화면별 파일

| 화면 | 원본 | 주석 이미지 | 주요 영역 |
|---|---|---|---|
| 홈 | `원본/01_홈.png` | `주석/01_홈_주석.png` | 탐색 메뉴, 새 문서, 최근 문서, 고정 프로젝트·빠른 템플릿, 미리보기 |
| 문서 편집기 | `원본/02_문서_편집기.png` | `주석/02_문서_편집기_주석.png` | 탐색, 서식 도구막대, 문서 작업 영역, 선택 수식, 수식 속성, 복사 메뉴 |
| 수식 빌더 | `원본/03_수식_빌더.png` | `주석/03_수식_빌더_주석.png` | 기호 팔레트, 수식 템플릿, 수식 작업 영역, LaTeX 코드, 속성·구조, 삽입·복사 |
| 레이아웃 | `원본/04_레이아웃.png` | `주석/04_레이아웃_주석.png` | 페이지 미리보기, 페이지 설정, 단 설정, 구조 스타일, 머리말·꼬리말, 페이지 관리 |
| 내보내기 | `원본/05_내보내기.png` | `주석/05_내보내기_주석.png` | 대상 선택, 수식 미리보기, 출력 형식, 내보내기 옵션, 빠른 복사, 프리셋·공유 |

## 참고

주석 이미지는 설명을 위해 원본 화면 옆에 기능 설명 패널을 더한 버전입니다. 원본 파일은 `원본/` 폴더에서 별도로 확인할 수 있습니다.
