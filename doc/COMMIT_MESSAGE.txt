Aether-Math 초기 구현: 수식 편집·저장·출력 경로를 추가한다

구조적 수식 AST와 세션 편집 모델을 바탕으로 템플릿 삽입, caret·선택·undo/redo, 행·그룹 조작, 속성·기호 팔레트 및 Unicode 탐색을 구성한다.

JSON 저장·열기와 recent/recovery 수명주기, 공유 layout을 사용하는 수식 렌더링·SVG·출력 미리보기, LaTeX 직렬화와 전체 코드 복사 경계를 추가한다. 제어 문자·필수 빈 슬롯·미지원 출력 정보를 진단하고 원본 수식 상태와 실패 파일을 보호한다.

루트 `.gitignore`는 생성물과 개인 IDE 상태·환경비밀만 좁게 제외하고 QA 근거, 디자인 자산, 역할 문서와 `.aethermath` 작업 파일은 추적 대상으로 보존한다.

LaTeX 코드 패널에는 원문 UTF-16 범위를 보존하는 표시용 토큰 snapshot과 강조 표시 전환 상태를 제공한다. 이 경로는 parser나 직렬화 동작을 변경하지 않는다.

검증 근거는 P1/P2 하위 단위별 QA 문서에 보존한다. LaTeX 구문 강조는 build05 0경고/0오류·exit0, 신규5-04 5/5·exit0, 전체210-01 210/210·exit0으로 승인됐다. 메인은 신규5-04 PNG 8개와 bounds 8개 핵심 필드를 직접 검토했고, 전체210의 8쌍은 자동 산출물이다. 초기 build/new5 실패와 수정 이력은 `doc/verification/P2-latex-highlight-QA.md` 및 `doc/verification/artifacts/p2-latex-highlight/`에 남긴다. 이 검증은 해당 slice의 논리·Headless/offscreen 동작만 확인하며 전체 제품 P0–P5 완료를 뜻하지 않는다. 실제 OS·IME·clipboard·UIA·AppData·computer-use, parser 및 외부 TeX 실행은 검증하지 않았다.
